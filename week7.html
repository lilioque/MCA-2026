Task 1

Create a second version of your MEI file with the updated metadata. To do this, open your original MEI file and select ‘Save As’. Then, edit your metadata.

My modified MEI file: o_fortuna_with_header2.mei

I did not know the formal genre attribution of O Fortuna, so I consulted a dedicated Wikipedia page but failed to find it there. So, I had to ask AI for help (see AI Use at the bottom of this page). Gemini suggested several options that could go as a genre (20th-Century Classical, Modern orchestral music, Choral Cantata, secular cantata, Secular cantata for choir and orchestra), but I decided that 'Secular cantata for choir and orchestra' is the most relevant one, since it covers both content, form, and performing forces.

For the license, I picked CC BY-NC-SA (Creative Commons NonCommercial-ShareAlike), because this file was created for educational purposes. I put this information in the <useRestrict> element, which is situated inside the <availability> element of the <pubStmt> section (as advised in the task and MEI Guidelines). I also chose to add @auth and @auth.uri attributes to provide a link to the license.
