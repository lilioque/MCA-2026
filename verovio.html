A note on Verovio/MEI results: Maybe due to the amount of extra information around the bars, the Verovio rendering of the score looks very clumsy and not at all as neat as it looked in MuseScore. That shows that even open standards do not guarantee full compatibility of everything with everything!

Task 2: Compare 3 XML elements in the MusicXML file to the corresponding ones in MEI. ... Think about: which attributes can be employed in each standard, which parents and children can be used, and try to think of the implications of these differences.

Element 1: metadata about the music piece (title, author, etc.)

Information about the piece title, composer, and part name is clearly labelled in the *.musicxml file through the use of the child elements of the element <credit> (<credit-type>title</credit-type>, <credit-type>composer</credit-type>, etc.), but in .mei they are just <rend> elements with the parent element <pgHead>. This is quite surprising, since the MEI standard is supposed to be more academic and research-oriented, but such basic information has been left unclassified. Moreover, the score that I digitised had name of the composer given in two languages, and the second line, containing the name in Latin script, went into another element, <pgFoot>, and is not visible on the page rendered by Verovio. That also means that this metadata cannot be properly parsed from the *.mei file.
